# Benchmark data manifest

Public datasets used by the fluorostats benchmarks and their figures.
Each row lists the dataset, the figure it backs, its licence, and where to obtain it.
Download into the directory pointed to by the `FLUOROSTATS_DATA` environment variable
(producers and figure scripts read `DATA` from `producers/common.py`, re-exported as
`figstyle.DATA`; it defaults to `data/downloads` under the repository root), preserving the sub-folder names noted below.
Figure numbers refer to the figure scripts in this folder (`fig2_*.py` … `fig5_*.py`, `figS1_*.py` … `figS4_*.py`)
and to the bundled `fig6_*` tables.
URLs verified 2026-09-24.

## Notes on figure reproducibility

- **Regenerating the bundled tables:** each `results/` table that public data can
  regenerate has a producer in `producers/` that reads the sub-folders named here
  under `$FLUOROSTATS_DATA`; `README.md` lists them with their verification status.
  Folder names the producers expect: `BBBC039/`, `BBBC024/`, `BBBC024_c25/`,
  `BBBC024_c50/`, `BBBC024_c75/`, `dsb2018/test/`, `CTC/<dataset>/`, `REAVER/`,
  `sproutangio/`, `viability/`, `kerkhoff_lda/synthetic/`, `vesselexpress/`.
- **BBBC024 deep-learning predictions** (`BBBC024_dl/`, read by
  `b_clustering_curve_dl.py`): derived, not downloaded. Copy the first 5 volumes of
  each BBBC024 set to `in/3d/<set>/` and the mid z plane (`shape[0] // 2`) of all 30
  to `in/2d/<set>/`, then on a node with Cellpose 3 and StarDist run
  `python cluster/bbbc024_dl_infer.py {cellpose,stardist} {3d,2d} in/<mode>/<set>
  BBBC024_dl/<mode>/<tool>/<set>` for each set. Each output folder holds one label
  TIFF per input and a `versions.json` (model, library versions, settings) that the
  producer copies into its `.run.json`.
- **BBBC039 repeat runs** (`BBBC039_dl_repeat/`, read by `b_dl_determinism.py`):
  the first 10 BBBC039 images (sorted) through the same script in `2d` mode 20 times
  per tool, each run a new process, written to `BBBC039_dl_repeat/<tool>/run_01` ...
  `run_20`.
- **One-CPU segmentation timing** (`BBBC039_timing/`, read by `b_seg_timing.py`): in
  one cluster job, on one node, the same 10 images through `cluster/fs_time.py`
  (fluorostats installed from a commit, named in `fs_commit.txt`) and through
  `cluster/bbbc024_dl_infer.py` for StarDist and Cellpose, 5 passes each, into
  `<tool>/pass_<k>/`, plus `node.json` (the CPU).
- **SproutAngio subset:** `b_vascular_sproutangio_multi.csv` covers 12 of the record's
  53 files: `group1-07..10`, `group3-04, -05, -09, -10`, `group5-03, -06, -10, -11` (`.czi`).
  Its producer reads every `.czi` in `sproutangio/`, so download exactly these.

- **Figures reproducible offline:** Fig 3, Fig 5, Fig S1, Fig S3, Fig S4 regenerate from
  the precomputed metric tables bundled in `results/` — no dataset download required.
- **Figures requiring a download:** Fig 2 (BBBC039, BBBC024, BBBC024_c75), Fig 4 (S-BIAD2130), Fig S2 (BBBC024).
  Fetch the dataset above into `$FLUOROSTATS_DATA/<subfolder>` and run the matching script.
- **Deep-learning baselines** (StarDist, Cellpose, Omnipose) were evaluated on an external
  GPU/ROCm cluster; their per-image outputs are shipped as CSVs in `results/`, so the
  comparison figures and tables regenerate without re-running the networks. See
  `VALIDATION.md`.
- **Application confocal data (the `fig6_*` tables: FITC-dextran penetration time-course;
  HUVEC/GelMA Live/Dead series)** are the originating laboratory's own microscopy. It remains with that
  laboratory and is available on request; it is not deposited. The closest public analogue
  listed above is S-BIAD2130. The derived per-stack tables *are* bundled as
  `results/fig6_*.csv`, so the quantitative panels can be recomputed without the raw stacks;
  the representative micrograph panel cannot, since it renders the raw data directly.

Datasets that were downloaded during exploration but back no figure or table here
(VascuSynth, S-BIAD2215, S-BIAD2920, and the VesselExpress sample volume `test.tiff`)
are deliberately not listed above.
