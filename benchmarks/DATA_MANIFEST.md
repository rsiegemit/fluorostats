# Benchmark data manifest

Each row lists the dataset, the figure it backs, its licence, and where to obtain it.
Download into the directory pointed to by the `FLUOROSTATS_DATA` environment variable
(the figure scripts read `figstyle.DATA`, which defaults to `./data/downloads` relative
to the repo root), preserving the sub-folder names noted below.
Figure numbering matches the manuscript (main figures 1–6; supplementary S1–S5).

## Notes on figure reproducibility

- **Figures reproducible offline:** Fig 3, Fig 5, Fig S1, Fig S3, Fig S4 regenerate from
  the precomputed metric tables bundled in `results/` — no dataset download required.
- **Figures requiring a download:** Fig 2 (BBBC039), Fig 4 (S-BIAD2130), Fig S2 (BBBC024).
  Fetch the dataset above into `$FLUOROSTATS_DATA/<subfolder>` and run the matching script.
- **Deep-learning baselines** (StarDist, Cellpose, Omnipose) were evaluated on an external
  GPU/ROCm cluster; their per-image outputs are shipped as CSVs in `results/`, so the
  comparison figures and tables regenerate without re-running the networks. See
  `VALIDATION.md`.
- **Application confocal data (Fig 6: FITC-dextran penetration time-course; HUVEC/GelMA
  Live/Dead series)** are the originating laboratory's own microscopy. It remains with that
  laboratory and is available on request; it is not deposited. The closest public analogue
  listed above is S-BIAD2130. The derived per-stack tables *are* bundled as
  `results/fig6_*.csv`, so the quantitative panels can be recomputed without the raw stacks;
  the representative micrograph panel cannot, since it renders the raw data directly.

Datasets that were downloaded during exploration but back no figure, table or claim in the
manuscript (VascuSynth, S-BIAD2215, S-BIAD2920) are deliberately not listed here.
