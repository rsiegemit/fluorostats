All URLs were fetched/verified 2026-07-08. Each row lists the dataset, the figure /
benchmark it backs, its licence, and where to obtain it. Download into the directory
pointed to by the `FLUOROSTATS_DATA` environment variable (the figure scripts read
`figstyle.DATA`, which defaults to `./data/downloads` relative to the repo root),
preserving the sub-folder names noted below.

## Notes on figure reproducibility

- **Figures reproducible offline:** Fig 3, Fig 5, ED 1, ED 3, ED 4 regenerate from the
  precomputed metric tables bundled in `results/` — no dataset download required.
- **Figures requiring a download:** Fig 2 (BBBC039), Fig 4 (S-BIAD2130), ED 2 (BBBC024).
  Fetch the dataset above into `$FLUOROSTATS_DATA/<subfolder>` and run the matching script.
- **Deep-learning baselines** (StarDist, Cellpose) were evaluated on an external GPU/ROCm
  cluster; their per-image outputs are shipped as CSVs in `results/`, so the comparison
  figures/tables regenerate without re-running the networks. See `VALIDATION.md`.
- **Application confocal data (Fig 6, lab GelMA/hybrid constructs)** are the authors' own
  microscopy and are not publicly deposited; the closest public analogues are listed above
  (S-BIAD2130, S-BIAD2920). The analysis scripts are provided; only these specific inputs
  are unavailable.
